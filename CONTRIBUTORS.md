## 🌟 How to Be Recognized

Forge welcomes all forms of contributions beyond code:
- **Code:** Bug fixes, performance improvements, LSP client integrations, and new features.
- **Documentation:** Tutorials, API documentation, typo fixes, and translation support.
- **Issue Triage & Bug Reports:** Reproducing edge cases, submitting clean bug reports, and verifying fixes.
- **Design & UI:** Theme tokens, icons, and usability feedback.

If you have contributed and your name or preferred handle is missing, please submit a pull request modifying this file!
