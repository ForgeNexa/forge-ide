## 2. Reporting a Vulnerability

The Forge team takes security vulnerabilities seriously. We ask that all security-sensitive issues be disclosed responsibly and confidentially.

### How to Report:
- **Email:** Please report security issues directly to maintainers via GitHub private security advisories:
  👉 https://github.com/manish-npx/forge/security/advisories/new
- **Information to Include:**
  1. A clear description of the vulnerability and its potential impact.
  2. Proof-of-concept code, minimal reproduction script, or exact reproduction steps.
  3. Affected platform(s) (macOS, Windows, Linux) and version of Forge.
  4. Any proposed remediations or patches, if available.

### What to Expect:
- You will receive an acknowledgment of your report within 48 hours.
- We will coordinate with you to validate the vulnerability and prepare a patch before public disclosure.
- We will credit you in the release notes and security advisory, unless you prefer to remain anonymous.

> [!CAUTION]
> Please do NOT create public GitHub issues or public forum posts for suspected zero-day vulnerabilities or security exploits.
